# Steel Coil Defect Detection

A machine learning project for detecting defective steel coils using industrial sensor data. The workflow includes data analysis, missing value imputation, feature engineering, model training with CatBoost, threshold optimization, and performance evaluation.

## Features

* Exploratory Data Analysis (EDA)
* Missing Value Handling using Iterative Imputer
* Feature Engineering
* CatBoost Classification Model
* Threshold Optimization
* Precision, Recall, F1-Score Evaluation

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-Learn
* CatBoost
* Jupyter Notebook

## Goal

Predict whether a steel coil is **Defective (1)** or **Non-Defective (0)** while maximizing defect detection performance.
